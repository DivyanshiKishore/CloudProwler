# Security Policy

## Supported Versions

This project is currently under active development.

| Version | Supported |
|---------|-----------|
| 1.x | ✅ Yes |

## Reporting a Vulnerability

If you discover a security issue within CloudProwler, please do not disclose it publicly before responsible disclosure.

Please report vulnerabilities by opening a private discussion or contacting the project maintainer with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

Verified security issues will be investigated and addressed in future releases.

## Disclaimer

CloudProwler is intended for authorized security assessments, cloud auditing, education, and defensive security purposes only. Users are responsible for ensuring they have permission to assess any AWS environment they scan.
